> AI를 공부하지 않으면 도태될 수 있다는 생각에, AI를 활용한 서비스 개발과 수익화를 목표로 ChatGPT와 함께 공부를 시작했다. 개발자 인터뷰에서 탑다운 방식으로 공부해 취업했다는 이야기를 보고 더 자극을 받았다. 이번에는 중간에 멈추지 않고 천천히, 꾸준히 공부하려고 한다.

## 개요

바이브 코딩, 업무 자동화, 게임 개발 등 AI를 활용한 다양한 작업을 하려면 먼저 **AI, 생성형 AI, LLM, 모델, 학습, 추론**이 각각 무엇인지 알아둘 필요가 있다.

ChatGPT와 같은 생성형 AI는 사람이 질문하면 데이터베이스에 저장된 정답을 찾아 그대로 보여주는 방식으로만 작동하지 않는다. 학습한 데이터의 패턴을 바탕으로 **입력된 문맥을 처리하고, 다음에 이어질 내용을 예측하며 결과를 생성한다.**

## AI와 생성형 AI는 무엇이 다른가?

**AI(Artificial Intelligence, 인공지능)**는 사람의 판단, 분류, 예측, 생성과 같은 작업을 컴퓨터가 수행하도록 만드는 기술 분야를 포괄하는 개념이다.

**생성형 AI**는 그중에서도 새로운 결과물을 만들어내는 AI를 의미한다. 대표적으로 다음과 같은 결과물을 생성할 수 있다.

- 텍스트
- 이미지
- 음성
- 영상
- 코드

따라서 모든 AI가 생성형 AI인 것은 아니다. 예를 들어 사진 속 사물이 고양이인지 강아지인지 **분류하는 AI**와 사용자의 요청을 받아 새로운 고양이 사진을 **생성하는 AI**는 목적이 다르다.

## LLM이란?

**LLM(Large Language Model, 대규모 언어 모델)**은 많은 양의 텍스트를 학습하여 언어의 패턴을 처리하는 AI 모델이다.

ChatGPT와 같은 서비스를 이해할 때는 **제품과 모델을 구분하는 것**도 중요하다.

- **ChatGPT:** 사용자가 AI 모델과 대화하고 여러 기능을 사용할 수 있도록 만든 제품
- **GPT:** ChatGPT 등에서 활용되는 AI 모델 계열
- **LLM:** GPT와 같은 대규모 언어 모델이 속하는 기술 범주

즉, ChatGPT와 GPT는 같은 것을 의미하지 않는다.

## 모델, 학습, 추론의 차이

AI를 공부하다 보면 **모델(Model), 학습(Training), 추론(Inference)**이라는 표현이 자주 등장한다.

### 모델(Model)

학습한 패턴을 바탕으로 입력을 받아 결과를 만들어내는 계산 시스템이다.

### 학습(Training)

많은 데이터를 이용해 모델이 패턴을 익히도록 만드는 과정이다.

### 추론(Inference)

학습이 끝난 모델에 새로운 입력을 전달하고 실제 결과를 생성하는 과정이다.

학생에 비유하면 이해하기 쉽다.

- **학습:** 책과 문제를 보며 공부하는 과정
- **모델:** 공부를 통해 형성된 학생의 현재 능력
- **추론:** 배운 내용을 바탕으로 새로운 문제에 답하는 과정

따라서 우리가 ChatGPT에 질문하고 답변을 받는 것은 대부분 **이미 학습된 모델을 이용해 추론하는 과정**에 해당한다. 대화를 할 때마다 GPT 모델 자체를 처음부터 다시 학습시키는 것은 아니다.

## LLM은 어떻게 문장을 만드는가?

LLM의 실제 구조는 복잡하지만, 기본적인 생성 과정은 다음과 같이 단순화할 수 있다.

```text
사용자 입력
    ↓
입력된 문맥 처리
    ↓
다음에 이어질 내용 예측
    ↓
생성
    ↓
다시 다음 내용 예측
    ↓
반복
    ↓
최종 답변
```

예를 들어 다음과 같은 문장이 있다고 가정해 보자.

> 오늘 점심은

이 문장 뒤에는 `김치찌개를 먹었다`, `파스타를 먹었다`, `먹지 않았다` 등 다양한 내용이 이어질 수 있다.

LLM은 학습한 패턴과 현재 문맥을 바탕으로 다음에 이어질 내용을 계산하고, 이 과정을 반복하면서 문장을 생성한다.

실제로는 문장을 그대로 처리하지 않고 **토큰(Token)**이라는 단위로 나누어 처리한다. 토큰은 다음 강의에서 별도로 다룬다.

## AI는 왜 틀린 정보를 만들까?

LLM은 기본적으로 **사실 데이터베이스에서 정답을 검색한 뒤 그대로 출력하는 시스템이 아니다.** 학습한 패턴과 주어진 문맥을 이용해 자연스러운 결과를 생성한다.

따라서 실제로 존재하지 않는 정보인데도 문맥상 그럴듯한 내용을 만들어낼 수 있다. 이러한 현상을 일반적으로 **환각(Hallucination)**이라고 부른다.

특히 AI를 이용해 개발할 때 이 특성을 이해하는 것이 중요하다. AI가 생성한 코드 역시 항상 정확하다고 가정할 수 없다.

예를 들어 AI에게 다음과 같이 요청했다고 가정해 보자.

> Roblox에서 플레이어의 돈을 저장하는 코드를 만들어줘.

AI는 그럴듯한 코드를 생성할 수 있다. 하지만 해당 코드가 현재 Roblox의 API에 맞는지, 적절한 위치에서 실행되는지, 데이터가 정상적으로 저장되는지, 보안상 문제가 없는지는 별도로 검증해야 한다.

따라서 바이브 코딩에서도 다음과 같은 과정이 필요하다.

```text
요구사항 정의
    ↓
AI를 이용한 코드 생성
    ↓
코드와 구조 확인
    ↓
실행
    ↓
오류 확인
    ↓
검증 및 수정
```

**AI가 생성한 결과물은 정답이 아니라 검증이 필요한 결과물로 보는 것이 안전하다.**

## 정리

이번 글에서 기억해야 할 개념은 다음과 같다.

| 용어 | 의미 |
| --- | --- |
| AI | 사람의 판단·분류·예측·생성 등의 작업을 컴퓨터가 수행하도록 만드는 기술 분야 |
| 생성형 AI | 텍스트, 이미지, 코드 등 새로운 결과물을 생성하는 AI |
| LLM | 많은 텍스트를 학습해 언어 패턴을 처리하는 대규모 언어 모델 |
| 모델 | 입력을 받아 학습된 패턴을 기반으로 결과를 만드는 계산 시스템 |
| 학습 | 데이터를 이용해 모델이 패턴을 익히는 과정 |
| 추론 | 학습된 모델이 새로운 입력을 받아 결과를 생성하는 과정 |
| 환각 | AI가 사실이 아닌 내용을 그럴듯하게 생성하는 현상 |

다음 글에서는 **토큰(Token)과 임베딩(Embedding)**을 통해 LLM이 사람의 문장을 어떻게 계산 가능한 형태로 처리하는지 알아볼 것이다.
