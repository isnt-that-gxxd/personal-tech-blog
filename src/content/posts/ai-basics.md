# AI 기초 개념 정리

AI는 데이터를 활용해 특정 작업을 수행하는 기술입니다.

## LLM이란?

LLM은 Large Language Model의 약자로,
대규모 언어 모델을 의미합니다.

## 토큰이란?

토큰은 언어 모델이 텍스트를 처리할 때 사용하는 단위입니다.

### 토큰과 컨텍스트

모델은 입력된 토큰을 컨텍스트 안에서 처리합니다.
